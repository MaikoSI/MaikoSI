## Sobre mim

Estudante do 2º semestre de Sistemas de Informação, apaixonado por tecnologia, robótica e inovação. Meu objetivo de carreira é me tornar um desenvolvedor de grande sucesso, buscando constantemente expandir minha lógica de programação através do aprendizado de múltiplas linguagens e da resolução de problemas.

Durante oito meses intensos de preparação, tive meu primeiro contato profundo com a lógica de desenvolvimento programando em rEduc (linguagem adaptada do C para o português), uma experiência prática que moldou minha visão e me inspirou a construir uma carreira sólida na área de desenvolvimento de software.
